# test-technique-cpam

## Description
Application simple qui parcourt les nombres de 1 à 6457 et applique les règles suivantes :

- multiple de 3 → "Patte"
- multiple de 5 → "Tatras"
- multiple de 3 et 5 → "Pattatras"
- sinon → le nombre
